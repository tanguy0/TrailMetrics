# PageHeader

En-tête de page : surtitre `kicker` mono en capitales (contexte : section, statut, date), titre `display-lg`, sous-titre `body-sm` muted, actions alignées à droite sur la ligne de base du titre.

- Trois actions maximum, en `sm` ; une seule primaire.
- Le surtitre remplace l'icône emoji de `.page-header__icon`.
