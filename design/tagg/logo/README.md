# Logo

Le mot-symbole **TAGG** est construit au trait (monoline, chapeaux ronds), comme les courbes de l'app. Le **A est un sommet** ; son apex porte le point de données en `terra` (sur fond clair) ou `sun` (sur fond sombre). Le symbole seul est ce A dans une tuile `radius-xl`.

| fichier | usage |
| --- | --- |
| `tagg-lockup.svg` | version complète, en-tête de page, exports PDF, blog |
| `tagg-lockup-on-rail.svg` | version complète sur le rail `bg-rail` ou tout fond sombre |
| `tagg-wordmark.svg` / `-inverse` | mot-symbole seul quand la tuile est déjà présente (ex. splash) |
| `tagg-mark.svg` | tuile : favicon, icône d'app, avatar, boutons 44 px |
| `tagg-mark-inverse.svg` | tuile claire sur fond `bg-rail` |

Règles : zone de protection = hauteur du T autour du logo ; hauteur minimale du mot-symbole 18 px, de la tuile 16 px ; jamais d'ombre, jamais de dégradé, jamais le mot-symbole en couleur autre que `ink` ou blanc. Le motto **Train · Analyse · Guide · Grow** se compose en `label` mono, espacement .26em, sous le mot-symbole uniquement sur les surfaces éditoriales (page d'accueil, PDF, blog), jamais dans le rail.
